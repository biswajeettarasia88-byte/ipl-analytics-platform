# Agents

The project utilizes specialized logical agents with distinct responsibilities:

1. **AGENT 1 — PROJECT ARCHITECT**: Overall architecture, folder structure, technology decisions, dependency management, architecture documentation.
2. **AGENT 2 — DATA ENGINEER**: Data acquisition, data ingestion, Bronze layer, source metadata, data storage.
3. **AGENT 3 — DATA QUALITY ENGINEER**: Schema validation, null checks, duplicate checks, referential integrity, range/business-rule validation, data quality reports.
4. **AGENT 4 — DATA TRANSFORMATION ENGINEER**: Cleaning, standardization, Silver layer, feature engineering, analytical datasets.
5. **AGENT 5 — DATABASE ENGINEER**: PostgreSQL, Star schema, Fact tables, Dimension tables, Indexes, Constraints, Analytical marts.
6. **AGENT 6 — SQL ANALYTICS ENGINEER**: Business questions, CTEs, Window functions, Advanced SQL, Analytical views, Insight generation.
7. **AGENT 7 — BI ENGINEER**: Power BI data model, Measures, KPIs, Dashboard design, Interactive filtering, Visualizations.
8. **AGENT 8 — MACHINE LEARNING ENGINEER**: Feature preparation, Baseline model, XGBoost, Time-based validation, Evaluation, Calibration, Model persistence.
9. **AGENT 9 — ML EXPLAINABILITY ENGINEER**: SHAP, Feature importance, Prediction explanation, Model interpretation.
10. **AGENT 10 — STREAMLIT ENGINEER**: Application, Analytics pages, Team explorer, Player explorer, Match predictor, Model explanation UI.
11. **AGENT 11 — QA ENGINEER**: Unit tests, Integration tests, Data tests, Application tests, Regression tests.
12. **AGENT 12 — DEVOPS ENGINEER**: Docker, GitHub Actions, CI, Environment configuration, Deployment preparation.
13. **AGENT 13 — DOCUMENTATION ENGINEER**: README, Architecture, Data dictionary, ERD, Data lineage, ML methodology, Limitations, Final report.
14. **AGENT 14 — REVIEWER**: Review the entire project, detect broken assumptions, bad architecture, leakage, fake/unsupported claims, incomplete implementation, and recommend corrections.
