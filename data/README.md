# Data Directory

This directory is strictly governed by the Medallion Architecture (Bronze -> Silver -> Gold). 

## Expected Structure
- `raw/`: Bronze layer. Place the raw `ipl_json.zip` extraction here. **Do NOT commit raw data.**
- `processed/`: Silver layer. Cleaned CSVs generated by `src/transformation/clean_data.py`.
- `marts/`: Analytics marts. Feature sets generated for Machine Learning (e.g., `mart_match_state.csv`).
- `sample/`: Contains a tiny subset of sanitized data exclusively for CI testing and demonstration purposes.

## How to Obtain Raw Data
1. Visit [Cricsheet](https://cricsheet.org/).
2. Download the `ipl_json.zip` file.
3. Extract the contents directly into `data/raw/` so that the JSON files populate the root of that folder.

*Note: The raw JSON datasets exceed GitHub's large file limits and contain thousands of files. They are explicitly ignored in `.gitignore`.*
