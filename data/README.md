# Data Directory Structure & Policy

This directory contains datasets used by the IPL Analytics & Decision Intelligence Platform.

## Policy
Due to repository size limits and licensing restrictions, the **full raw Cricsheet data** is NOT committed to this GitHub repository. This ensures a clean and small repository while preventing accidental tracking of large datasets.

## Acquiring the Data
1. Download the JSON IPL datasets directly from [Cricsheet](https://cricsheet.org/downloads/ipl_json.zip).
2. The expected date version should ideally match the 2024 season completion (or latest).

## Directory Structure
- **`data/raw/`**: Extract the downloaded `.json` files here. These are ignored by Git.
- **`data/staging/`**: Intermediate converted datasets (Parquet/JSON chunks) generated by ingestion. Ignored by Git.
- **`data/processed/`**: The final clean `matches.csv` and `deliveries.csv` files used by the analytics engine and ML pipeline. Ignored by Git.
- **`data/marts/`**: Contains pre-computed analytical views and feature sets. Ignored by Git.
- **`data/sample/`**: A tiny, safe sample dataset committed to Git for unit testing purposes.

## Running Ingestion
To populate the database from raw data, simply run:
```bash
python src/ingestion/ingest.py
```
